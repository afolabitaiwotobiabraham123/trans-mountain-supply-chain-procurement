# Power BI Dashboard

This folder contains the Power BI dashboard and supporting screenshots developed for the Trans Mountain Supply Chain, Procurement & Forecasting Analytics project.

The dashboard will present historical procurement performance, supplier reliability, material availability, and forecasting results in an interactive and business-focused format.

## Dashboard Objectives

- Monitor procurement spending and purchasing patterns.
- Evaluate supplier delivery performance and reliability.
- Track purchase order completion and delivery delays.
- Monitor material availability and inventory performance, where data is available.
- Visualize forecasted procurement expenditure.
- Present predicted material demand and future purchasing requirements.
- Communicate forecasting accuracy and model performance.
- Support procurement planning and supply chain decision-making.

## Folder Structure

### dashboard/
Stores the Power BI dashboard file (`.pbix`).

### screenshots/
Stores screenshots of dashboard pages, visualizations, and important analytical findings.

## Dashboard Components

- Procurement Performance Dashboard
- Supplier Performance Dashboard
- Materials and Inventory Dashboard
- Forecasting Dashboard

## Tools
- Microsoft Power BI
- Power Query
- DAX

## Data Sources
The dashboard will use prepared datasets, historical analysis results, and forecasting outputs from the Python and MySQL workflows.

**Note:** Dashboard metrics and visualizations will depend on the actual dataset fields and analytical results available.
