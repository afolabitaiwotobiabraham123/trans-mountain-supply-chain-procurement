# Project Documentation

This folder contains the supporting documentation for the Trans Mountain Supply Chain, Procurement & Forecasting Analytics project.

It provides information about the data sources, dataset structure, field definitions, procurement KPIs, and forecasting evaluation metrics used throughout the project.

## Documentation Files

### data_sources.md
Documents the datasets used in the project, their sources, collection methods, accessibility, and limitations.

### data_dictionary.md
Describes the fields in the collected datasets, including field names, data types, meanings, measurement units, and relevant observations.

### kpi_definitions.md
Documents the procurement, supplier performance, materials, inventory, and forecasting KPIs used in the project, including their definitions, calculation methods, and business relevance.

## Documentation Principles

- Use verified information from the actual datasets.
- Clearly distinguish publicly sourced data from simulated data.
- Document data limitations and analytical assumptions.
- Define KPIs and forecasting evaluation metrics before using them.
- Keep documentation consistent with the Python, MySQL, forecasting, and Power BI work.
