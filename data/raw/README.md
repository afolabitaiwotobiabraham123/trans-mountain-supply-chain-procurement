# Raw Data

This folder stores the original, unmodified datasets collected for the Trans Mountain Supply Chain, Procurement & Forecasting Analytics project.

The datasets may contain information relating to:

- Procurement and purchasing activities.
- Purchase orders.
- Supplier performance.
- Material demand and consumption.
- Inventory and stock availability.
- Delivery performance and lead times.
- Historical procurement expenditure.

Original datasets will be preserved before exploratory analysis, data quality assessment, cleaning, or transformation.

This ensures data traceability and allows the original source data to remain available for reference.
