# Processed Data

This folder stores the datasets after data quality assessment, cleaning, transformation, and preparation using Python and Pandas.

The prepared datasets will be structured for further analysis using MySQL and visualization using Power BI.

Processed datasets may include:

- Cleaned procurement records.
- Prepared purchase order data.
- Supplier performance datasets.
- Material demand and consumption datasets.
- Inventory records, where available.
- Delivery performance and lead-time datasets.
- Prepared historical data for forecasting.

All data preparation decisions and transformations will be documented to maintain consistency, traceability, and analytical reliability.

Original source datasets will remain preserved in the raw data folder.
