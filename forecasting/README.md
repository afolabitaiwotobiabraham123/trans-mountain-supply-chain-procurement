# Forecasting and Predictive Analytics

This folder contains the Jupyter Notebooks used to develop, test, and evaluate forecasting models for the Trans Mountain Supply Chain, Procurement & Forecasting Analytics project.

Python and relevant forecasting libraries will be used to analyze historical procurement and supply chain data, identify trends, and estimate future requirements.

## Forecasting Notebooks

### 01_procurement_spend_forecasting.ipynb
Analyzes historical procurement expenditure and develops forecasting models to estimate future purchasing costs and spending patterns.

### 02_material_demand_forecasting.ipynb
Examines historical material demand and consumption patterns to estimate future material requirements and support inventory and procurement planning.

### 03_supplier_lead_time_forecasting.ipynb
Analyzes historical supplier delivery lead times to estimate future delivery durations and identify potential procurement delays, where sufficient data is available.

### 04_forecast_evaluation.ipynb
Evaluates forecasting model performance using appropriate error metrics, compares model results, and documents forecasting limitations.

## Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Scikit-learn
- Appropriate time-series forecasting libraries, where required

## Forecasting Workflow

Historical Data → Trend Analysis → Forecast Model Development → Predictions → Model Evaluation → Business Recommendations

## Important Considerations

- Forecasting models will be selected based on the structure and historical coverage of the available datasets.
- Forecast accuracy will be evaluated before predictions are used for business recommendations.
- Forecasts will be treated as estimates, not guaranteed future outcomes.
- Any simulated data used will be clearly identified.
- Forecasting activities that cannot be supported by the available data will not be presented as completed analysis.
